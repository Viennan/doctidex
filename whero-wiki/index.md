# Reference Wiki

This corpus contains locally preserved provider documentation for agent research.
Collected pages are immutable snapshots and may lag current official
documentation. Follow the narrowest relevant provider directory, then use its
filenames and headings to locate exact guidance or schema details.

## Providers

- [Alibaba Cloud Model Studio](aliyun/) — Guides and API references for Qwen,
  embeddings, image and video generation, files, tools, rate limits, and
  OpenAI- or Anthropic-compatible interfaces.
- [Anthropic](anthropic/) — Claude onboarding, model interaction guidance,
  agent skills, MCP, and built-in or client-defined tool use.
- [DeepSeek](deepseek/) — API onboarding, generation features, caching, tool
  calls, operational limits, pricing, and agent integrations.
- [OpenAI](openai/) — Developer guides plus focused API references for
  Responses, files, embeddings, and image operations.
- [Volcano Engine Ark](volengine/) — Ark guides and API references for text,
  multimodal, image and video generation, Responses, files, embeddings, tools,
  and context management.
