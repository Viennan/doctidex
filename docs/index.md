# 设计与项目治理文档

本目录保存 `doctidex` 工件的当前非规范性设计和项目治理记录。每个工件拥有跨实现的
Architecture 及按条件划分的 Impls；项目共用 Requirements 历史和经用户授权创建的
Issues 记录。

- [doctidex-git](doctidex-git/index.md)：Git agent plugin 的共同 Architecture、已安装的
  public surface 与 Python Impls。
- [Requirements](requirements/index.md)：项目级意图、设计决策、实现状态、批准与双向依赖。
- [Issues](issues/index.md)：由 review 或用户报告收集、经用户授权记录的问题、证据和处置状态。
