# Implementation Documentation

This directory contains the maintained non-normative design documentation for
doctidex implementations. Each implementation owns its current Architecture and
concrete Details; the project shares one Requirements history.

- [doctidex-git](doctidex-git/index.md) documents the Git-backed agent plugin,
  its public workflows, and the Python reference implementation.
- [Requirements](requirements/index.md) records project-wide intent, design
  decisions, implementation state, approval, and reciprocal dependencies.
