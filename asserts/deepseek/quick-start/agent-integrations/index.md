# DeepSeek Agent Integrations

These collected guides describe tool-specific setup at snapshot time. Read the
guide for the exact tool in use; do not generalize environment variables, model
mapping, or compatibility fields across different integrations.

- [Deep Code](deep-code.md) - Installation, configuration, launch, shortcuts,
